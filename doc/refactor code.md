# Yaniga Diamond

## Project Goal

พัฒนาเว็บไซต์ Yaniga Diamond ใหม่ทั้งหมด โดยอ้างอิงจากเว็บไซต์เดิม

เป้าหมายคือ

- ปรับโครงสร้าง Frontend ให้เป็น Angular
- พัฒนา Backend ด้วย NestJS
- ใช้ MySQL เป็นฐานข้อมูล
- แยก Component และ Module ให้ชัดเจน
- รองรับการเพิ่มฟีเจอร์ในอนาคตโดยไม่ต้องแก้โครงสร้างหลัก

เว็บไซต์เดิมใช้

- HTML
- CSS

- JavaScript

ซึ่งทำให้การดูแลและขยายระบบทำได้ยาก

เว็บไซต์ใหม่จะถูกออกแบบใหม่ทั้งหมด โดยเน้น

- Clean Architecture
- Reusable Component
- Responsive Design
- API First
- Scalability
